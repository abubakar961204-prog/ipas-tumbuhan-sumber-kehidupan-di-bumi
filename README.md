# IPAS Kelas 4 SD — Evaluasi Bab 1: Tumbuhan, Sumber Kehidupan di Bumi

Repositori ini berisi **paket soal evaluasi lengkap** dan **aplikasi kuis web interaktif** untuk mata pelajaran **Ilmu Pengetahuan Alam dan Sosial (IPAS) Kelas 4 SD (Kurikulum Merdeka) Bab 1: Tumbuhan, Sumber Kehidupan di Bumi**.

## Cakupan Materi

1. **Topik A — Bagian Tubuh Tumbuhan dan Fungsinya**
   - Akar (tunggang, serabut, dan umbi akar), batang, daun (bentuk tulang daun dan fungsi), bunga, buah, serta biji.
2. **Topik B — Fotosintesis, Proses Paling Penting di Bumi**
   - Kebutuhan fotosintesis (cahaya matahari, air, karbon dioksida, dan klorofil), hasil fotosintesis (karbohidrat/glukosa dan oksigen), serta peran tumbuhan sebagai produsen.
3. **Topik C — Perkembangbiakan Tumbuhan**
   - Bagian-bagian bunga (benang sari, putik, mahkota, kelopak), proses penyerbukan dan perantaranya, penyebaran biji, serta perkembangbiakan vegetatif alami dan buatan.

## Isi Repositori

- [`soal-evaluasi.md`](soal-evaluasi.md) — Paket soal evaluasi siap baca/cetak lengkap dengan kisi-kisi, **20 soal pilihan ganda**, **10 soal isian singkat**, **5 soal uraian (HOTS)**, kunci jawaban, pembahasan, dan pedoman penskoran.
- [`index.html`](index.html), [`styles.css`](styles.css), [`data.js`](data.js), [`app.js`](app.js) — Aplikasi kuis evaluasi interaktif berbasis web tanpa dependensi eksternal (langsung jalan di browser maupun GitHub Pages).

## Cara Menggunakan

### 1. Paket Soal Tertulis / Cetak
Buka berkas [`soal-evaluasi.md`](soal-evaluasi.md) untuk menggunakan soal secara langsung di kelas, lembar kerja siswa, atau bahan latihan mandiri.

### 2. Kuis Web Interaktif
- Buka berkas `index.html` langsung di browser, **atau**
- Aktifkan **GitHub Pages** pada menu **Settings → Pages → Branch: `main` (`/ (root)`)** untuk mengakses kuis secara daring.

### Fitur Kuis Interaktif
- **Pilihan Paket:** Evaluasi Lengkap (20 soal) atau latihan per topik (Topik A, B, atau C).
- **Dua Mode Pengerjaan:**
  - *Mode Latihan*: menampilkan jawaban benar dan pembahasan langsung setelah memilih jawaban.
  - *Mode Ujian*: menghitung nilai akhir dan menampilkan pembahasan lengkap setelah seluruh soal selesai.
- **Rekap Nilai Per Topik:** Membantu siswa dan guru melihat topik mana yang sudah dikuasai dan yang perlu pendalaman.
